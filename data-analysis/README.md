# 📊 Mall Customer Segmentation - Data Analysis

This folder contains the complete Jupyter/Colab notebook for **exploring**, **visualizing**, and **segmenting** mall customers based on their demographic and behavioral data using clustering techniques.

## 📁 Folder Contents

- **`mall_customers_segmentation.ipynb`**  
  A complete end-to-end notebook that includes:
  - Data loading and cleaning
  - Exploratory Data Analysis (EDA)
  - Feature encoding and scaling
  - K-Means clustering with Elbow Method
  - Dimensionality reduction using PCA and t-SNE
  - Cluster-based customer insights and marketing strategies
  - Evaluation using Silhouette Score

- **`README.md`**  
  You are here — this file explains the purpose of the `data-analysis` folder.

## 📌 Key Techniques Used

- ✅ Pandas & NumPy for data manipulation  
- ✅ Seaborn & Matplotlib for visualizations  
- ✅ Scikit-learn for clustering (K-Means), evaluation (Silhouette Score), PCA, and t-SNE  
- ✅ Domain insights for customer profiling and business strategy suggestions

## 📊 Clustering Objective

Segment customers based on:
- **Age**
- **Gender**
- **Annual Income**
- **Spending Score**

Resulting clusters are then analyzed to suggest **tailored marketing strategies** based on common characteristics within each segment.
