# 🛍️ Mall Customers Dataset

## 📄 Overview

The **Mall Customers Dataset** contains information about 200 individuals who visit a shopping mall. It includes demographic attributes such as gender and age, along with financial data like annual income and spending score. This dataset is ideal for customer segmentation, behavioral analysis, and clustering using machine learning techniques.

## 📊 Dataset Summary

- **Total Records**: 200 rows  
- **Total Features**: 5 columns  
- **Missing Values**: None  

## 📁 Columns Description

| Column Name             | Description                                                                 |
|-------------------------|-----------------------------------------------------------------------------|
| `CustomerID`            | Unique identifier for each customer (integer)                              |
| `Genre`                 | Gender of the customer (Male/Female)                                       |
| `Age`                   | Age of the customer (integer)                                              |
| `Annual Income (k$)`    | Annual income in thousands of dollars (integer)                            |
| `Spending Score (1-100)`| Score assigned by the mall based on customer behavior and spending (integer)|

## 🔍 Potential Use Cases

- **Customer Segmentation**: Identify groups of customers based on income and spending habits.
- **Behavioral Analysis**: Analyze how age, gender, and income impact consumer behavior.
- **Clustering**: Use algorithms like K-Means for unsupervised clustering.
- **Targeted Marketing**: Develop personalized marketing strategies for different customer segments.

## 📥 Source

This dataset is publicly available on [Kaggle](https://www.kaggle.com/datasets/amisha0528/mall-customers-dataset).

Simply place the dataset file (e.g., `Mall_Customers.csv`) in this folder for analysis and modeling tasks.
